# เว็บไซต์ "ข้อสอบ" — รวบรวมข้อสอบหลายวิชา

เว็บไซต์สำหรับนักเรียนทดลองทำข้อสอบ สุ่มข้อสอบจากคลังใหญ่ พร้อมจับเวลาและระบบสมาชิก
สร้างจาก brief ที่ลูกค้ากรอกมา (ดูสรุปคำตอบด้านล่าง) — **เนื้อหาทั้งหมดตอนนี้เป็นข้อมูลตัวอย่าง (placeholder)** เพราะยังไม่ได้รับเนื้อหาจริงจากลูกค้า

## สถานะตอนนี้ — โหมดตัวอย่าง (Demo Mode)

`assets/site.js` ตั้ง `APP.demoMode = true` ไว้ ทำให้:
- สมัคร/ล็อกอิน/ทำข้อสอบ/ส่งฟอร์มติดต่อ/แสดงความเห็น **ทำงานจำลองในเบราว์เซอร์ทั้งหมด** ไม่มีข้อมูลส่งออกไปไหนจริง
- ข้อสอบที่ทำเป็นโจทย์ตัวอย่างสุ่มขึ้นมา (ไม่ใช่เนื้อหาวิชาจริง) และผลคะแนนเป็นการจำลอง ไม่ใช่การตรวจจริง
- เปิดเว็บดูได้ทันทีโดยไม่ต้องตั้งค่าอะไรเพิ่ม เหมาะสำหรับให้ลูกค้าดูหน้าตาและทดลองใช้งานก่อน

## ไฟล์ในโปรเจกต์

```
index.html        หน้าแรก
subjects.html      รายชื่อวิชา (primaryGoal ตาม brief)
exam.html          หน้าทำข้อสอบ (?subject=slug) — สุ่มข้อสอบ + จับเวลา + ล็อกอินก่อนทำ
news.html          ข่าวสาร / กิจกรรม
downloads.html     ดาวน์โหลดเอกสาร
feedback.html      พื้นที่แสดงความเห็น
contact.html       ติดต่อเรา (ฟอร์ม + Facebook Page)
login.html / register.html / account.html   ระบบสมาชิก
assets/style.css   ธีมกลาง (ปรับสีได้ที่ :root)
assets/site.js     ตั้งค่ากลาง (โทเค็น, endpoint, ลิงก์ Facebook, อีเมลติดต่อ)
assets/demo-data.js วิชา/ข่าว/เอกสารตัวอย่าง — แก้เป็นข้อมูลจริงตรงนี้ได้เลย
assets/og-image.png, assets/favicon.png  รูปที่สร้างให้ตามธีม
gas/Code.gs        หลังบ้าน Google Apps Script (สมาชิก + สุ่มข้อสอบ + ตรวจให้คะแนน + ฟอร์ม)
```

## ขั้นตอนเชื่อมระบบจริง (ก่อนใช้งานจริงต้องทำ)

1. **สร้าง Google Sheet ใหม่** แล้วสร้างชีตย่อยตามนี้ (หัวตารางระบบจะสร้างให้อัตโนมัติเมื่อมีข้อมูลแรกเข้ามา ยกเว้นชีตคลังข้อสอบที่ต้องกรอกเอง):
   - `Q_<slug วิชา>` เช่น `Q_thai-m3` — คอลัมน์: `id | type | text | options | answer | score | note`
     - `type` ใส่ `mc` (ปรนัย) หรือ `tf` (ถูก/ผิด)
     - `options` คั่นตัวเลือกด้วย `|` เช่น `กรุงเทพ|เชียงใหม่|ภูเก็ต|ขอนแก่น`
     - `answer` ต้องตรงกับหนึ่งใน options เป๊ะ ๆ (ห้ามพิมพ์ผิด ไม่งั้นจะตรวจว่าผิดตลอด)
     - ทำหนึ่งชีตต่อหนึ่งวิชา ให้ครบทุก slug ที่อยู่ใน `assets/demo-data.js` (หรือแก้ slug ในไฟล์นั้นให้ตรงกับที่ใช้จริง)
   - ชีต `Users`, `Contact`, `Feedback`, `Results` ไม่ต้องสร้างเอง ระบบสร้างให้อัตโนมัติ

2. **วางโค้ดหลังบ้าน**: เปิดชีต → Extensions → Apps Script → ลบโค้ดเดิม → วางเนื้อหาจาก `gas/Code.gs`
   - แก้ `CONTACT_EMAIL` เป็นอีเมลที่จะรับข้อความจากฟอร์มติดต่อ
   - `TOKEN` ในไฟล์ตั้งไว้แล้วเป็น `exam-bank-a217053bc9a2` (ต้องตรงกับ `APP.token` ใน `assets/site.js` — ตอนนี้ตรงกันอยู่แล้ว ไม่ต้องแก้ถ้าไม่ได้เปลี่ยน)

3. **Deploy**: Deploy → New deployment → เลือกประเภท **Web app** → Execute as **Me** → Who has access **Anyone** → Deploy → คัดลอก URL ที่ได้

4. **เชื่อมหน้าเว็บกับหลังบ้าน**: เปิด `assets/site.js` แล้วแก้
   ```js
   demoMode: false,
   endpoint: "URL ที่ได้จากขั้นตอนที่ 3",
   facebook: "ลิงก์ Facebook Page จริง",
   contactEmail: "อีเมลเดียวกับที่ตั้งใน Code.gs",
   ```

5. **ใส่เนื้อหาจริง**: แก้ `assets/demo-data.js` (รายวิชา ข่าว เอกสาร) ให้เป็นข้อมูลจริง และเติมคลังข้อสอบในชีต `Q_<slug>` ของแต่ละวิชา

6. **ขึ้น GitHub Pages**: Settings → Pages → Deploy from branch → เลือก branch นี้ → root → บันทึก จะได้ลิงก์ `https://wanchagaa-spec.github.io/exam/`

7. **ทดสอบ 1 รอบเต็ม**: สมัครสมาชิก → ล็อกอิน → เลือกวิชา → ทำข้อสอบจนครบเวลา/ส่งคำตอบ → ดูคะแนน → เช็กว่าแถวข้อมูลลงชีต `Results` ถูกคอลัมน์ → ลองส่งฟอร์มติดต่อดูว่าอีเมลเข้าจริง

## สิ่งที่ยังต้องได้จากลูกค้า (ตามที่คุยกันไว้ตอนรับงาน)

- **เนื้อหาเว็บจริง**: ชื่อวิชาทั้งหมด ข่าว/กิจกรรม เอกสารดาวน์โหลด — ตอนนี้เป็นข้อมูลตัวอย่างในไฟล์ `assets/demo-data.js`
- **คลังข้อสอบจริงพร้อมเฉลย** ของแต่ละวิชา (จำเป็นมาก ไม่มีข้อสอบจริงก็ใช้งานจริงไม่ได้)
- ลิงก์ **Facebook Page** จริง และอีเมลที่จะรับข้อความจากฟอร์มติดต่อ

## ข้อจำกัดที่ต้องแจ้งลูกค้าไว้ล่วงหน้า

- ระบบสมาชิกนี้เหมาะกับการฝึกทำข้อสอบทั่วไป **ไม่ใช่ระบบความปลอดภัยระดับองค์กร** (รหัสผ่านถูกแฮชก่อนเก็บ แต่ Google Apps Script ไม่เหมาะกับข้อมูลอ่อนไหว เช่น เลขบัตรประชาชนหรือข้อมูลการเงิน)
- นักเรียนทำข้อสอบซ้ำได้หลายครั้งเพื่อฝึกฝน (แต่ละครั้งได้ชุดข้อสอบสุ่มใหม่) — ถ้าต้องการทำได้ครั้งเดียวสำหรับสอบจริงแจ้งได้ ปรับได้
- ยังไม่มีระบบป้องกันการโกงขั้นสูง (เช่น ตรวจจับสลับหน้าจอ) เพิ่มได้ภายหลังถ้าต้องการ
- Google Sheets มีข้อจำกัดจำนวนแถว/การเรียกใช้งานพร้อมกัน หากมีนักเรียนทำข้อสอบพร้อมกันจำนวนมากมาก ๆ ควรพิจารณาย้ายไปฐานข้อมูลอื่นในอนาคต
- GitHub Pages เป็นโฮสต์แบบ static ไม่มีค่าใช้จ่าย ใช้โดเมนรูปแบบ `username.github.io/ชื่อ repo` (ถ้าต้องการโดเมนของตัวเอง เช่น `.ac.th` ต้องซื้อแยกและตั้งค่า custom domain เพิ่ม)
