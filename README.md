# เว็บไซต์ "ข้อสอบ" — รวบรวมข้อสอบหลายวิชา

เว็บไซต์สำหรับนักเรียนทดลองทำข้อสอบ สุ่มข้อสอบจากคลังใหญ่ พร้อมจับเวลาและระบบสมาชิก
สร้างจาก brief ที่ลูกค้ากรอกมา (ดูสรุปคำตอบด้านล่าง) — **เนื้อหาทั้งหมดตอนนี้เป็นข้อมูลตัวอย่าง (placeholder)** เพราะยังไม่ได้รับเนื้อหาจริงจากลูกค้า

## สถานะตอนนี้ — โหมดตัวอย่าง (Demo Mode)

`assets/site.js` ตั้ง `APP.demoMode = true` ไว้ ทำให้:
- สมัคร (ด้วยอีเมล)/ล็อกอิน/ทำข้อสอบ/ส่งฟอร์มติดต่อ/โพสต์ในบอร์ดความคิดเห็น **ทำงานจำลองในเบราว์เซอร์ทั้งหมด** ไม่มีข้อมูลส่งออกไปไหนจริง
- เปิดเว็บดูได้ทันทีโดยไม่ต้องตั้งค่าอะไรเพิ่ม เหมาะสำหรับให้ลูกค้าดูหน้าตาและทดลองใช้งานก่อน
- **หน้าแอดมิน (`admin.html`) ใช้งานได้ในโหมดตัวอย่างเช่นกัน** — รหัสผ่านคือ `admin123` (ดูตัวแปร `APP.demoAdminPassword` ใน `assets/site.js`) เพิ่มข้อสอบ + ตั้งโครงสร้างชุดข้อสอบผ่านหน้านี้แล้วไปลองทำข้อสอบที่ `subjects.html` ได้ทันที ระบบจะสุ่มและตรวจให้คะแนนจริงจากข้อที่เพิ่มไว้ (ข้อมูลเก็บเฉพาะในเบราว์เซอร์เครื่องนี้ ยังไม่ได้ขึ้นชีตจริง)
- ถ้ายังไม่ได้ตั้งโครงสร้างชุดข้อสอบของวิชานั้น ระบบจะสุ่มจากคลังทั้งหมดแทน (สูงสุด 10 ข้อ) ถ้าคลังว่างเปล่าด้วย จะใช้โจทย์ตัวอย่างที่ยังไม่มีเนื้อหาจริงและคะแนนเป็นการจำลอง

## ไฟล์ในโปรเจกต์

```
index.html        หน้าแรก
subjects.html      รายชื่อวิชา (primaryGoal ตาม brief)
exam.html          หน้าทำข้อสอบ (?subject=slug) — สุ่มข้อสอบ + จับเวลา + ล็อกอินก่อนทำ
news.html          ข่าวสาร / กิจกรรม (ประกาศจากผู้ดูแลเว็บไซต์เท่านั้น)
downloads.html     ดาวน์โหลดเอกสาร
contact.html       ติดต่อเรา (ฟอร์ม + Facebook Page)
search.html        ผลค้นหา (?q=คำค้น) — ค้นทั้งรายวิชาและโพสต์ในบอร์ดความคิดเห็น
login.html / register.html / account.html   ระบบสมาชิกนักเรียน — account.html คือหน้าโปรไฟล์ (รูป + โพสต์ของตัวเอง)
admin.html         หน้าแอดมิน (ล็อกอินด้วยรหัสผ่านแยกต่างหาก) เพิ่ม/ลบข้อสอบพร้อมเฉลยเต็มในคลัง — ลิงก์อยู่มุมล่างของทุกหน้า
assets/style.css   ธีมกลาง (ปรับสีได้ที่ :root)
assets/site.js     ตั้งค่ากลาง (โทเค็น, endpoint, ลิงก์ Facebook, อีเมลติดต่อ)
assets/demo-data.js วิชา/ข่าว/เอกสารตัวอย่าง + SUBJECT_STRANDS (ลิสต์สาระของแต่ละวิชา) — แก้เป็นข้อมูลจริงตรงนี้ได้เลย
assets/og-image.png, assets/favicon.png  รูปที่สร้างให้ตามธีม
gas/Code.gs        หลังบ้าน Google Apps Script (สมาชิก + สุ่มข้อสอบ + ตรวจให้คะแนน + ฟอร์ม)
```

## ขั้นตอนเชื่อมระบบจริง (ก่อนใช้งานจริงต้องทำ)

1. **สร้าง Google Sheet ใหม่** — ไม่ต้องสร้างชีตย่อยเองเลย ทุกชีต (`Users`, `Contact`, `Posts`, `Likes`, `Comments`, `Results`, `Blueprint`, และ `Q_<slug>` ของแต่ละวิชา) ถูกสร้างอัตโนมัติเมื่อมีข้อมูลแรกเข้ามา
   - **สมาชิก** ล็อกอินด้วย **อีเมล** (ไม่มีชื่อผู้ใช้/username แล้ว) ตอนสมัครกรอกชื่อที่แสดง อายุ โรงเรียน อีเมล และรหัสผ่าน — เก็บในชีต `Users` แก้ไขรูปโปรไฟล์ได้ที่หน้า `account.html` (ย่อขนาด + เก็บเป็น data URL ตรงในเซลล์ชีต ไม่มีระบบเก็บไฟล์แยก)
   - **บอร์ดความคิดเห็น** ต้องล็อกอินก่อนถึงจะโพสต์/ถูกใจ/คอมเมนต์ได้ — โพสต์ได้ทุกหน้าผ่านปุ่ม **+** บน header (เปิดเป็นหน้าต่างโพสต์ทันที ไม่ต้องเปลี่ยนหน้า) โพสต์แยกตามหมวดหมู่ = 9 วิชา ดูโพสต์ของตัวเองได้ที่หน้าโปรไฟล์ `account.html` (กรองตามวิชา/เรียงตามใหม่ล่าสุดหรือถูกใจมากที่สุดได้ที่หน้า `search.html`) ลบโพสต์/คอมเมนต์ของตัวเองได้ ข้อมูลอยู่ในชีต `Posts`, `Likes`, `Comments` — มีการแจ้งเตือน (กระดิ่งบน header) เมื่อมีคนถูกใจ/คอมเมนต์โพสต์ของเรา เก็บในชีต `Notifications` (เช็กยอดตอนโหลดหน้าเว็บ ไม่ใช่ real-time)
   - คลังข้อสอบ (`Q_<slug>`) เติมได้ 2 ทาง: **(แนะนำ)** ผ่านหน้า `admin.html` บนเว็บ หรือจะพิมพ์ลงชีตตรง ๆ ก็ได้ — คอลัมน์คือ `id | type | text | options | answer | score | note | strand`
     - `type` ใส่ `mc` (ปรนัย), `tf` (ถูก/ผิด) หรือ `fill` (เติมคำตอบ พิมพ์เอง)
     - `options` คั่นตัวเลือกด้วย `|` เช่น `กรุงเทพ|เชียงใหม่|ภูเก็ต|ขอนแก่น` (type เป็น tf หรือ fill ปล่อยว่างได้)
     - `answer` สำหรับ mc/tf ต้องตรงกับหนึ่งใน options เป๊ะ ๆ — สำหรับ `fill` ใส่คำตอบที่ยอมรับได้หลายแบบ คั่นด้วย `|` เช่น `10|๑๐|สิบ` ตอบถูกถ้าตรงแบบใดแบบหนึ่ง
     - `strand` คือสาระ/หมวดเนื้อหาของข้อนั้น ต้องพิมพ์ให้ตรงกับชื่อใน `SUBJECT_STRANDS` (`assets/demo-data.js`) เป๊ะ ๆ ไม่งั้นระบบสุ่มตามโครงสร้างจะหาไม่เจอ — ถ้าเพิ่มผ่าน `admin.html` เลือกจากลิสต์อยู่แล้วไม่มีปัญหานี้
     - พิมพ์สมการคณิตศาสตร์ในช่อง `text`/`note` แบบ LaTeX ได้ โดยคร่อมด้วย `$...$` เช่น `$x^2+1$` — หน้าเว็บ (ทั้ง `admin.html` และ `exam.html`) โหลดไลบรารี **KaTeX จาก CDN ภายนอก** มาแสดงเป็นสมการสวยงามอัตโนมัติ
     - slug ของแต่ละวิชาต้องตรงกับใน `assets/demo-data.js`
   - **โครงสร้างชุดข้อสอบ** (ชีต `Blueprint`) กำหนดผ่านหน้า `admin.html` แท็บ "โครงสร้างชุดข้อสอบ" — เลือกวิชา แต่ละวิชาสร้างโครงสร้างได้ **หลายชุด** ตั้งชื่อแยกกันได้ (เช่น "ชุดที่ 1", "ชุดปรับปรุง 2569") บันทึกแล้วอยู่ถาวรในชีต ลบหรือแก้ทีหลังได้ตลอด — แต่ละชุดเพิ่มส่วนต่าง ๆ (ส่วนที่ 1, 2, ...) พร้อมระบุว่าแต่ละส่วนสุ่มกี่ข้อจากสาระไหน หน้าจอจะโชว์จำนวนข้อที่มีในคลังของแต่ละสาระให้เทียบก่อนบันทึกด้วย เลือกได้ว่าจะ "ใช้งาน" ชุดไหน (มีได้ทีละ 1 ชุด active ต่อวิชา) — ระบบจะสุ่มข้อสอบตามชุดที่ active อยู่เท่านั้นทุกครั้งที่นักเรียนเริ่มทำข้อสอบ ถ้ายังไม่ตั้งโครงสร้างเลย ระบบจะสุ่มจากคลังทั้งหมดแทน (สูงสุด 10 ข้อ)

2. **วางโค้ดหลังบ้าน**: เปิดชีต → Extensions → Apps Script → ลบโค้ดเดิม → วางเนื้อหาจาก `gas/Code.gs`
   - แก้ `ADMIN_PASSWORD` เป็นรหัสผ่านที่จะใช้เข้าหน้า `admin.html` (ต้องเปลี่ยนจากค่าเริ่มต้นก่อนใช้งานจริงเสมอ)
   - แก้ `CONTACT_EMAIL` เป็นอีเมลที่จะรับข้อความจากฟอร์มติดต่อ
   - `TOKEN` ในไฟล์ตั้งไว้แล้วเป็น `exam-bank-a217053bc9a2` (ต้องตรงกับ `APP.token` ใน `assets/site.js` — ตอนนี้ตรงกันอยู่แล้ว ไม่ต้องแก้ถ้าไม่ได้เปลี่ยน)

3. **Deploy**: Deploy → New deployment → เลือกประเภท **Web app** → Execute as **Me** → Who has access **Anyone** → Deploy → คัดลอก URL ที่ได้

4. **เชื่อมหน้าเว็บกับหลังบ้าน**: เปิด `assets/site.js` แล้วแก้
   ```js
   demoMode: false,
   endpoint: "URL ที่ได้จากขั้นตอนที่ 3",
   facebook: "ลิงก์ Facebook Page จริง",
   contactEmail: "อีเมลเดียวกับที่ตั้งใน Code.gs",
   ```

5. **ใส่เนื้อหาจริง**: แก้ `assets/demo-data.js` (รายวิชา ข่าว เอกสาร สาระของแต่ละวิชา) ให้เป็นข้อมูลจริง แล้วเข้า `admin.html` (ด้วยรหัสผ่านที่ตั้งใน `ADMIN_PASSWORD`) เพื่อ:
   - เพิ่มข้อสอบพร้อมเฉลยของแต่ละวิชา (แท็บ "นำเข้าข้อมูล (JSON)" — วางเป็น JSON array แล้วนำเข้าทีเดียวทั้งชุด ดูรูปแบบตัวอย่างในความช่วยเหลือของแท็บนั้น) — ติดแท็กสาระให้ครบทุกข้อ ดูรายการ/ลบข้อสอบที่มีอยู่ได้ที่แท็บ "คลังข้อสอบ"
   - ตั้ง "โครงสร้างชุดข้อสอบ" ของแต่ละวิชา (แท็บ "โครงสร้างชุดข้อสอบ") ว่าแต่ละส่วนสุ่มกี่ข้อจากสาระไหน — สร้างได้หลายชุดต่อวิชา แล้วเลือกกดปุ่ม "ใช้ชุดนี้" ให้ชุดที่ต้องการใช้จริงเป็นชุด active

6. **ขึ้น GitHub Pages**: Settings → Pages → Deploy from branch → เลือก branch นี้ → root → บันทึก จะได้ลิงก์ `https://wanchagaa-spec.github.io/exam/`

7. **ทดสอบ 1 รอบเต็ม**: เข้า `admin.html` เพิ่มข้อสอบสัก 2–3 ข้อต่อสาระ ตั้งโครงสร้างชุดข้อสอบ → สมัครสมาชิก → ล็อกอิน → เลือกวิชา → ทำข้อสอบจนครบเวลา/ส่งคำตอบ → ดูคะแนนและเฉลยแยกตามส่วน → เช็กว่าแถวข้อมูลลงชีต `Results` ถูกคอลัมน์ → ลองส่งฟอร์มติดต่อดูว่าอีเมลเข้าจริง

## สิ่งที่ยังต้องได้จากลูกค้า (ตามที่คุยกันไว้ตอนรับงาน)

- **เนื้อหาเว็บจริง**: ข่าว/กิจกรรม เอกสารดาวน์โหลด — ตอนนี้เป็นข้อมูลตัวอย่างในไฟล์ `assets/demo-data.js`
- **คลังข้อสอบจริงพร้อมเฉลย** ของแต่ละวิชา ที่เขียนขึ้นเอง (จำเป็นมาก ไม่มีข้อสอบจริงก็ใช้งานจริงไม่ได้)
- **รายชื่อสาระ/หมวดเนื้อหาที่ต้องการจริง** ของแต่ละวิชา (ตอนนี้ใน `SUBJECT_STRANDS` เป็นชื่อสาระตัวอย่างตามหมวดหมู่เนื้อหาทั่วไป ควรแก้ให้ตรงกับที่จะใช้จริงก่อนเริ่มใส่ข้อสอบจำนวนมาก เพราะเปลี่ยนชื่อสาระทีหลังต้องไปแก้ข้อสอบเก่าที่ติดแท็กไว้แล้วด้วย)
- **เงื่อนไขโครงสร้างชุดข้อสอบ** ของแต่ละวิชา (กี่ส่วน แต่ละส่วนกี่ข้อจากสาระไหน) — ตั้งได้เองผ่าน `admin.html` เมื่อพร้อม
- ลิงก์ **Facebook Page** จริง และอีเมลที่จะรับข้อความจากฟอร์มติดต่อ

## ข้อจำกัดที่ต้องแจ้งลูกค้าไว้ล่วงหน้า

- ระบบสมาชิกและหน้าแอดมินนี้เหมาะกับการฝึกทำข้อสอบทั่วไป **ไม่ใช่ระบบความปลอดภัยระดับองค์กร** (รหัสผ่านนักเรียนถูกแฮชก่อนเก็บ ส่วนรหัสผ่านแอดมินตรวจจากค่าคงที่ใน `Code.gs` ทุกครั้งที่ใช้งาน ไม่มีการล็อกบัญชีเมื่อพิมพ์ผิดหลายครั้ง) อย่าใช้รหัสผ่านแอดมินซ้ำกับบัญชีอื่นที่สำคัญ และอย่าเก็บข้อมูลอ่อนไหว เช่น เลขบัตรประชาชนหรือข้อมูลการเงินไว้ใน Sheet นี้
- นักเรียนทำข้อสอบซ้ำได้หลายครั้งเพื่อฝึกฝน (แต่ละครั้งได้ชุดข้อสอบสุ่มใหม่) — ถ้าต้องการทำได้ครั้งเดียวสำหรับสอบจริงแจ้งได้ ปรับได้
- ยังไม่มีระบบป้องกันการโกงขั้นสูง (เช่น ตรวจจับสลับหน้าจอ) เพิ่มได้ภายหลังถ้าต้องการ
- Google Sheets มีข้อจำกัดจำนวนแถว/การเรียกใช้งานพร้อมกัน หากมีนักเรียนทำข้อสอบพร้อมกันจำนวนมากมาก ๆ ควรพิจารณาย้ายไปฐานข้อมูลอื่นในอนาคต
- สมการคณิตศาสตร์ใช้ไลบรารี **KaTeX โหลดจาก CDN ภายนอก** (jsdelivr) ถ้าอินเทอร์เน็ตของโรงเรียน/นักเรียนบล็อก CDN นี้ สมการจะไม่ขึ้นสวยงาม (ขึ้นเป็นโค้ดดิบแทน) แต่เนื้อหาข้อความปกติและการทำข้อสอบยังใช้งานได้ตามเดิม
- คำตอบแบบเติมคำ (`fill`) ตรวจแบบข้อความ ไม่รองรับการตรวจสมการที่เขียนต่างรูปแบบแต่ค่าเท่ากัน (เช่น `1/2` กับ `0.5` ถือว่าต่างกัน) ต้องให้แอดมินใส่คำตอบที่ยอมรับทุกแบบเองในช่อง "คำตอบที่ยอมรับ"
- GitHub Pages เป็นโฮสต์แบบ static ไม่มีค่าใช้จ่าย ใช้โดเมนรูปแบบ `username.github.io/ชื่อ repo` (ถ้าต้องการโดเมนของตัวเอง เช่น `.ac.th` ต้องซื้อแยกและตั้งค่า custom domain เพิ่ม)
