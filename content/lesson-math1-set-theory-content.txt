หมายถึง กลุ่มของสิ่งต่างๆ ที่ระบุสมาชิกได้ชัดเจน เช่น เซตของจำนวนนับ $\mathbb{N}$ สิ่งที่อยู่ในเซตเรียกว่า "สมาชิก"
สัญลักษณ์ ให้ $x$ เป็นสมาชิกของเซต $A$ จะเขียนแทนด้วย $x \in A$

สับเซต
นิยาม: เซต $A$ ถือเป็นสับเซตของเซต $B$ ก็ต่อเมื่อสมาชิกทุกตัวของเซต $A$ เป็นสมาชิกของเซต $B$ ด้วย เขียนแทนด้วย $A \subset B$

การเขียนเซต แบ่งเป็น 2 แบบ คือ
1) แบบแจกแจงสมาชิก เช่น $\{1,2,3\}$
2) แบบบอกเงื่อนไข เช่น $\{x \mid x \in \mathbb{R}\}$

การดำเนินการระหว่างเซต

อินเตอร์เซกชันของเซต
ให้ $A$ และ $B$ เป็นเซต เขียนแทนด้วย $A \cap B$ โดยที่ $A \cap B = \{x \mid x \in A \text{ และ } x \in B\}$
![แผนภาพเวนน์-ออยเลอร์ แสดง A ∩ B](assets/graphs/venn-intersection.svg)

ยูเนียนของเซต
ให้ $A$ และ $B$ เป็นเซต เขียนแทนด้วย $A \cup B$ โดยที่ $A \cup B = \{x \mid x \in A \text{ หรือ } x \in B\}$
![พื้นที่ระบายสีแสดง A ∪ B](assets/graphs/venn-union.svg)

ผลต่างระหว่างเซต
ให้ $A$ และ $B$ เป็นเซต เขียนแทนด้วย $A - B$ โดยที่ $A - B = \{x \mid x \in A \text{ และ } x \notin B\}$
![พื้นที่ระบายสีแสดง A - B](assets/graphs/venn-difference.svg)

คอมพลีเมนต์ของเซต
ให้ $A$ เป็นเซต และ $U$ เป็นเอกภพสัมพัทธ์ เขียนแทนด้วย $A'$ โดยที่ $A' = \{x \mid x \in U \text{ และ } x \notin A\}$
![พื้นที่ระบายสีแสดง A′](assets/graphs/venn-complement.svg)

สมบัติของการดำเนินการของเซต
ให้ $A, B$ และ $C$ เป็นสับเซตของเอกภพสัมพัทธ์ $U$ จะได้
1) $A \cup B = B \cup A$ และ $A \cap B = B \cap A$
2) $(A \cup B) \cup C = A \cup (B \cup C)$ และ $(A \cap B) \cap C = A \cap (B \cap C)$
3) $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$ และ $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$
4) $(A \cup B)' = A' \cap B'$ และ $(A \cap B)' = A' \cup B'$ (กฎเดอมอร์แกน)
5) $A - B = A \cap B'$
6) $A' = U - A$
7) ถ้า $A \subset B$ แล้ว $A - B = \varnothing$

การหาจำนวนสมาชิกของเซตจำกัด

เซตจำกัด 2 เซต
$$n[A \cup B] = n[A]+n[B]-n[A \cap B]$$
$$n\big[(A-B)\cup(B-A)\big] = n[A]+n[B]-2\,n[A \cap B]$$

เซตจำกัด 3 เซต
$$n[A \cup B \cup C] = n[A]+n[B]+n[C]-n[A \cap B]-n[A \cap C]-n[B \cap C]+n[A \cap B \cap C]$$

เพาเวอร์เซต
นิยาม: ให้ $X$ เป็นเซตใด ๆ เพาเวอร์เซต (power set) ของ $X$ เขียนแทนด้วย $P(X)$ คือเซตของสับเซตทั้งหมดของ $X$ นั่นคือ
$$P(X) = \{A \mid A \subset X\}$$
กล่าวคือ สำหรับเซต $A$ ใด ๆ
$$A \in P(X) \iff A \subset X$$

สมบัติของเพาเวอร์เซต
1) $\varnothing \in P(X)$ และ $X \in P(X)$ เสมอ ดังนั้น $P(X) \neq \varnothing$ ทุกกรณี (แม้ $X = \varnothing$)
2) ถ้า $X$ เป็นเซตจำกัดที่ $n(X) = n$ แล้ว $n(P(X)) = 2^n$
3) $P(\varnothing) = \{\varnothing\}$ และ $n(P(\varnothing)) = 2^0 = 1$ (ระวัง: $\{\varnothing\} \neq \varnothing$)
4) $A \subset B \iff P(A) \subset P(B)$

ตัวอย่าง 1
$P(\{1,2\}) = \{\varnothing, \{1\}, \{2\}, \{1,2\}\}$ มี $2^2 = 4$ สมาชิก

ตัวอย่าง 2
สมมติให้เซต $A = \{1, 2\}$ จงหาจำนวนสมาชิกทั้งหมดของ $P(A)$
เขียนสับเซตทั้งหมดของเซต $A$ จะได้ว่า $P(A) = \{\varnothing, \{1\}, \{2\}, \{1, 2\}\}$
นั่นคือ จำนวนสมาชิกทั้งหมดของเซต $P(A)$ มี 4 ตัว หรือเนื่องจากเซต $A$ มีสมาชิกทั้งหมด 2 ตัว ดังนั้น $2^2 = 4$
ตอบ จำนวนสมาชิกทั้งหมดของ $P(A)$ คือ 4

ตัวอย่าง 3 (A-Level 69)
สำหรับเซต $S$ ใด ๆ ให้ $P(S)$ แทนเพาเวอร์เซตของ $S$ ให้เซต $A = \{\varnothing, \sqrt{2}\}$ แล้วเซต $P(P(A) \cup P(A))$ มีสมาชิกกี่ตัว
วิธีทำ เนื่องจากเซต $A = \{\varnothing, \sqrt{2}\}$ มีสมาชิก 2 ตัว
$$n[P(A)] = 2^2 = 4$$
$$n[P(P(A))] = 2^4 = 16$$
จะหา $n[P(P(A)) \cup P(A)]$ จากสูตร $n[A \cup B] = n[A]+n[B]-n[A \cap B]$
$$n[P(P(A)) \cup P(A)] = n[P(P(A))] + n[P(A)] - n[P(P(A)) \cap P(A)]$$
พิจารณา $P(A) = \{\varnothing, \{\varnothing\}, \{\sqrt{2}\}, \{\varnothing, \sqrt{2}\}\}$ แล้วเช็คทีละสมาชิกว่าเป็นสับเซตของ $P(A)$ หรือไม่
- $\varnothing \subset P(A)$ เป็นจริง
- $\{\varnothing\} \subset P(A)$ เป็นจริง
- $\{\sqrt{2}\}$ มีสมาชิกคือ $\sqrt{2}$ ซึ่ง $\sqrt{2} \notin P(A)$ จึงไม่เป็นสับเซต
- $\{\varnothing, \sqrt{2}\}$ มีสมาชิกคือ $\sqrt{2}$ ซึ่ง $\sqrt{2} \notin P(A)$ จึงไม่เป็นสับเซต
ดังนั้น $n[P(P(A)) \cap P(A)] = 2$
แทนค่า $n[P(P(A)) \cup P(A)] = 4+16-2 = 18$
ตอบ ข้อ 3 คือ 18

ตัวอย่าง 4 (A-Level 69)
กำหนดให้ $A, B, C$ เป็นเซต โดยที่ $n(A)=40$, $n(A \cap B)=27$, $n(A \cap C)=21$ และ $n(A \cap B \cap C)=10$ จงหาจำนวนสมาชิกของเซต $A-(B \cup C)$
วิธีทำ เนื่องจาก $n(A \cap B \cap C) = 10$
$$n(A \cap B) - n(A \cap B \cap C) = n[(A \cap B) - C] = 27 - 10 = 17$$
$$n(A \cap C) - n(A \cap B \cap C) = n[(A \cap C) - B] = 21 - 10 = 11$$
ดังนั้น
$$n[A-(B \cup C)] = n[A]-n[(A\cap B)-C]-n[(A\cap C)-B] = 40-17-11-10 = 2$$
ตอบ จำนวนสมาชิกของเซต $A-(B\cup C)$ คือ 2
