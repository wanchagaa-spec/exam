นำเข้าข้อสอบหลายข้อ (JSON)

อัปโหลดรูปประกอบโจทย์

เลือกรูป ระบบจะย่อขนาดและอัปโหลดขึ้น Google Drive ให้อัตโนมัติ ได้ข้อความอ้างอิงกลับมาเป็น ![alt](url) — คัดลอกไปวางในตำแหน่งที่ต้องการภายใน text หรือ note ของ JSON ด้านล่างได้เลย

นำเข้าข้อมูล (JSON)

วางข้อมูลเป็น JSON array แล้วกดนำเข้า ระบบจะเพิ่มทีละข้อเข้าคลังของ "วิชาที่เลือกไว้ด้านบน" แต่ละข้อเป็น object: { "type":"mc|tf|fill", "strand":"ชื่อสาระ", "text":"โจทย์", "options":["..."], "answer":"...", "score":3, "note":"คำอธิบายเฉลย" } — strand ต้องตรงกับชื่อในลิสต์สาระของวิชานั้นเป๊ะ ๆ, type fill ไม่ต้องมี options และใส่คำตอบที่ยอมรับได้หลายแบบใน answer คั่นด้วย |
