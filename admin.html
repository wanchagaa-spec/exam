เพิ่มข้อสอบใหม่

ใช้ตอนกำหนด "โครงสร้างชุดข้อสอบ" ว่าแต่ละส่วนจะสุ่มกี่ข้อจากสาระไหน

พิมพ์สมการคณิตศาสตร์ได้ด้วยการคร่อมด้วย $ เช่น $x^2+1$ หรือ $\frac{1}{2}$ ระบบจะแสดงเป็นสมการสวยงามให้อัตโนมัติ (ใช้ได้ทั้งในช่องโจทย์ ตัวเลือก และคำอธิบายเฉลย)

ติ๊กวงกลมหน้าช่องที่เป็นคำตอบที่ถูก กรอกอย่างน้อย 2 ตัวเลือก เว้นช่องที่ไม่ใช้ไว้ได้

ระบบจะตรวจว่าถูกถ้านักเรียนพิมพ์ตรงกับคำตอบแบบใดแบบหนึ่งในนี้ (ไม่สนตัวพิมพ์เล็ก-ใหญ่และช่องว่างเกิน)

ตัวอย่างที่นักเรียนจะเห็น

วางข้อมูลเป็น JSON array แล้วกดนำเข้า ระบบจะเพิ่มทีละข้อเข้าคลังของ "วิชาที่เลือกไว้ด้านบน" แต่ละข้อเป็น object: { "type":"mc|tf|fill", "strand":"ชื่อสาระ", "text":"โจทย์", "options":["..."], "answer":"...", "score":3, "note":"คำอธิบายเฉลย" } — strand ต้องตรงกับชื่อในลิสต์สาระของวิชานั้นเป๊ะ ๆ, type fill ไม่ต้องมี options และใส่คำตอบที่ยอมรับได้หลายแบบใน answer คั่นด้วย |
